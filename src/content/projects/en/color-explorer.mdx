## The problem

Working with colour usually means jumping between a picker, a converter, a palette generator and a contrast checker. I wanted all four in one fast page — and I wanted the colour maths to be correct, not just plausible.

## What I built

- **Picker & conversions.** Accepts any CSS colour — `#ff8800`, `rgb()`, `hsl()`, `oklch()` or a named colour — and copies it as HEX, RGB, HSL or OKLCH in one click.
- **Palette generator.** Complementary, analogous, triadic, tints and shades. Hue maths runs in **OKLCH**, a perceptually uniform space, and results are gamut-mapped back to sRGB so every swatch is displayable.
- **Contrast checker.** Live WCAG 2.x ratio with AA and AAA pass/fail for normal and large text, a preview and a swap button.
- **Save & share.** Palettes are saved in the browser, and the full state lives in the URL hash.

## Engineering notes

- **Pure core, thin UI.** All colour logic lives in a framework-free `lib/` folder with its own unit tests; React components only render it.
- **Tests and linting in CI.** Vitest and Testing Library cover the logic and components, Oxlint keeps the codebase clean, and GitHub Actions runs both on every push.
- **Automated deploys.** Merges to `main` build and publish the app to GitHub Pages.
