## The goal

A portfolio is often the first code a recruiter or engineer sees, so I wanted it to show the same habits I bring to backend work: measurable performance, security by default and a delivery process that doesn't depend on being careful.

## What I built

- **Static first.** Astro renders every page to HTML at build time, with content collections for case studies and typed data for experience and skills. Only the interactive pieces ship JavaScript.
- **A hero that earns its weight.** The animated service graph started on three.js, which cost seconds of main-thread time on mobile. I rewrote it as a small raw WebGL renderer with its own matrix helpers, loaded only when the browser is idle and skipped for reduced-motion users.
- **Locked down.** A strict Content Security Policy is generated at build time, and security headers are served from the edge, so the site works with no inline scripts or styles.
- **Bilingual.** English at `/` and Turkish under `/tr`, with localized routes, metadata and a contact form.

## Delivery

Every change goes through a pull request to a protected `main` branch. GitHub Actions runs lint, Prettier, `astro check` and a production build, and Lighthouse CI must pass before a merge is allowed. Merged changes are built and deployed to Cloudflare Workers static assets.

## What's next

Automated visual regression tests and a small blog for write-ups on backend topics.
