# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-12

First public release of utkukucuk.com.

### Added

- Astro + TypeScript + Tailwind CSS v4 project with ESLint, Prettier and `astro check` ([#1](https://github.com/utku-kucuk/utkukucuk.com/pull/1))
- GitHub Actions CI (lint, format, types, build, Lighthouse), Dependabot, PR/issue templates ([#2](https://github.com/utku-kucuk/utkukucuk.com/pull/2))
- Design system with dark/light themes, header, footer and EN/TR routing ([#4](https://github.com/utku-kucuk/utkukucuk.com/pull/4))
- Interactive WebGL service-graph hero with intro animation ([#5](https://github.com/utku-kucuk/utkukucuk.com/pull/5))
- About, Experience and Stack sections; smooth scroll, reveals, counters, cursor ([#6](https://github.com/utku-kucuk/utkukucuk.com/pull/6))
- Selected work with pinned horizontal scroll and bilingual case studies ([#7](https://github.com/utku-kucuk/utkukucuk.com/pull/7))
- Contact section with email, CV downloads and Web3Forms form ([#8](https://github.com/utku-kucuk/utkukucuk.com/pull/8))
- Open Graph images, JSON-LD, hashed CSP, security headers and 404 page ([#9](https://github.com/utku-kucuk/utkukucuk.com/pull/9))
